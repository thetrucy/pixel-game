# 🚀 Lil Moonie - OOP Final Project Game

## Project Overview

Lil Moonie is a 2D side-scrolling action game inspired by Dead Cells and Hollow Knight,
but with a simplified scope. Players will combat with enemies to complete level.

## Core Gameplay Loop

**The game features:**

* Player Movement & Combat: Responsive controls for character movement and attack actions.

* Enemy Encounters: AI-driven enemies with distinct behaviors.

* Level Progression: Navigate through a single, polished level.

* Win/Loss Conditions: Clear objectives for success and failure.

## How to Play
### Controls
* **Movement:** WAD (W: Jump, A: Left, D: Right)
* **Heal:** S
* **Dash:** Left shift

* **Attack/Combo Attack:** Left Mouse Click

### Objectives

Defeat all enemies in the level.

## Installation & Setup
To get the project running on your local machine, follow these steps:

### Prerequisites
Unity Editor.

Git: Installed on your system for version control.

### Cloning the Repository
1. Open your terminal or Git Bash.

2. Navigate to the directory where you want to store the project.

3. Clone the repository using the following command:
```
git clone https://github.com/thetrucy/pixel-game
```
4. Navigate into the cloned project directory:
```
cd lil-moon-game-project # Replace with your actual project folder name
```
**Opening in Unity Editor**
1. Open Unity Hub.

2. Click on "Add" and navigate to the lil-moonie-game-project directory you just cloned. Select the root folder.

3. Ensure the correct Unity Editor version (2022.3.15f1) is selected.

4. Click "Open Project" to launch the game in the Unity Editor.

## Building the Game
You can build the game for Windows or Linux directly from the Unity Editor.

1. Open Build Settings
In the Unity Editor, go to File > Build Settings.

2. Select Platform
* For Windows (.exe):

  * Select PC, Mac & Linux Standalone.
  
  * Set Target Platform to Windows.
  
  * Set Architecture to x86_64.

* For Linux:

  * Select PC, Mac & Linux Standalone.
  
  * Set Target Platform to Linux.
  
  * Set Architecture to x86_64.

(Ensure you have the Linux Build Support module installed via Unity Hub if you haven't already).

3. Build and Run
* Click "Switch Platform" if prompted.

* Click "Build" or "Build And Run".

* Choose a destination folder to save your build.

* The executable file (e.g., Lil Moonie.exe for Windows, or Lil Moonie.x86_64 for Linux) and its associated _Data folder will be generated in your chosen location.
